## 4. 逐项检查

### 正确性

- [ ] 状态机覆盖非法路径（未确认要点能批改吗？重复分配会怎样？）
- [ ] 幂等：重复提交 / 重复回调 / 重试不会产生两份数据或两次扣费
- [ ] 并发：两人同时审同一卷、同时触发重生成
- [ ] 失败路径：模型超时、输出不合规、上游 5xx，用户看到什么、能否重试

### 数据与安全

- [ ] 每个查询都带 tenant，且 tenant 来自会话而非 body/query/header
- [ ] 权限点已声明；数据范围（assigned/self）在 repository 生效
- [ ] 日志 / 错误上报无 PII、密钥、答卷原文
- [ ] 上传有类型/大小/数量限制；下载链接短时签名

### AI 与前端（本项目重点）

- [ ] 面向用户的 AI 交互是流式的（`streamText` / SSE），无"等完整结果再渲染"
- [ ] 长任务：202 + jobId；SSE 进度事件可续传（`id` / `Last-Event-ID`）
- [ ] 结构化输出经过 Schema 校验；失败重试 ≤ 2 次后报 `AI_OUTPUT_INVALID`
- [ ] 结构化内容用 CopilotKit Generative UI（`useCopilotAction` + `render`），组件只吃校验后数据
- [ ] 模型 Key 只在服务端；前端无模型 SDK 依赖
- [ ] 成本：token 上限、重试次数、缓存策略明确
- [ ] 交付文本中的分数/题号来自结构化数据，非模型编造

### 工程

- [ ] 无 `any`、`@ts-ignore`、`catch {}`、静默返回空数组
- [ ] 没有复制粘贴出第二套实现；依赖方向 controller → service → repository
- [ ] 测试测的是逻辑，不是把被测对象 mock 掉；无 e2e
- [ ] 文档 / OpenAPI / 迁移同步更新；回滚方式可执行
- [ ] 无顺手重构；PR 变更 ≤ 400 行（生成物除外）
