# 功能文档（需求 + 开发计划）

> 约定：每个新功能**先**在这里写需求文档与开发计划，确认后才动代码（见 `../baseline/05-engineering-baseline.md` §15.3）。
> 命名：`YYYYMMDD-<slug>.md`，与 CR 报告同名（放 `../codereviews/`）。
> 状态流转：草案 → 已确认 → 开发中 → 待 CR → 已完成（或"搁置"）。
